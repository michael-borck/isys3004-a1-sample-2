# Alex Chen — Web Portfolio

A personal portfolio documenting my journey through the Web Fundamentals unit at Curtin University.

**Live site:** https://michael-borck.github.io/isys3004-a1-sample-2/

Built with vanilla HTML, CSS, and JavaScript — no frameworks.

> **Staff exemplar:** Alex Chen is a fictional persona created for teaching purposes. See `NOTES-FOR-EDUCATORS.md` for context on how this resource is intended to be used.

## What's in this repo

| File / Folder | Purpose |
|---------------|---------|
| `*.html` | Site pages |
| `css/` | Stylesheets (one per page + shared `base.css`) |
| `js/` | JavaScript (nav injection, animations, API, form) |
| `CODE-GUIDE.md` | Walkthrough of key code patterns — start here for viva prep |
| `KNOWN-ISSUES.md` | Acknowledged shortfalls, documented professionally |
| `NOTES-FOR-EDUCATORS.md` | Staff context on this exemplar |
| `docs/reflection.md` | Placeholder reflection (structure and quality guide) |
| `docs/conversations/` | AI conversation placeholders (thinking + build, Weeks 2–5) |
| `docs/validation/` | Lighthouse and W3C validation results |
| `docs/superpowers/` | Design spec and implementation plan from the Claude Code workflow |

## For students

- Read **`CODE-GUIDE.md`** before your viva — it explains what the code is doing and why
- Read **`KNOWN-ISSUES.md`** to see how to document shortfalls professionally
- The `docs/conversations/` files show the structure of strong thinking and build chats
- The `docs/validation/` files show what validation reports should contain and how to run the tools yourself

## AI Acknowledgements

This project was developed using Claude (Anthropic) — both Claude.ai for thinking conversations and Claude Code (CLI) for the structured build workflow. All code has been reviewed and verified by a human. AI assistance is disclosed in the footer of every page.

The `.superpowers/` and `docs/superpowers/` folders contain artefacts from the Claude Code workflow (brainstorm visuals, design spec, implementation plan). These are left visible as an example of transparent AI-assisted development.
